###################
Version 4.0.0 |Pro|
###################

This release includes the following **internal changes**:

* Regenerate types for Buffer<T> and adapt backend to the new type
* Add types regeneration script
* Regenerate types with Fast DDS Gen Pro v4.4.0 and include license
* Fix missing Gtest dependency declaration

This release includes the following **bugfixes**:

* Added mock for update_endpoint_discovery_source and update of C++ version to 17
* Removed monitor process participants discovery
* Fix empty Domain View after loading an offline recording
* Fix offline-mode type schema lookup and Image View not rendering images with non-octet byte element types

This release includes the following **features**:

* Menu option to stop monitoring a domain
* Add Topic-Name Profile Lookup for Entity Creation
* Create statistics DataReaders on demand
* Register Data Type from IDL and under a custom name via alias
* Spy types with large truncated collections
* Offline mode (Open recording)
* Configure Custom User Topics as Image-Compatible Topics
* Register SOME IP Bridge app
* Rename references of Fast DDS Monitor to DDS Monitor
